- This is a web application to play a video that is available locally on a 
computer without first uploading to the server. 

- It is able to move the video playback back and forth while playing with keyboard buttons. 
It can also step forwards, backwards, pause and unpause.

- Uses standard html5, css, javascript so we can easily turn it into a 
desktop application using Electron framework in the future if necessary

- It should use python as the backend
- It should use Bulma CSS as css framework

- Don't just add code, feel free to remove code when it is no longer needed, or refactor existing code to make it more efficient or simpler


# How to run
$ python -m venv venv
$ . venv/activate/bin
$ python app.py
